## ref-log.txt

This project uses a Retrieval-Augmented Generation (RAG) method.  
Models and methods used:

- **Model for embeddings:** openai.text-embedding-3-small  
- **Model for chat:** openai.o3-mini  
- **Retrieval method:** ConversationalRetrievalChain  
- **Vector database:** Chroma  
- **Document parsing:** pdfplumber
